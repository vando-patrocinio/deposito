## Diferenças importantes (frequentemente confundidas)

| Você quer... | Vá para |
|--------------|---------|
| Conectar OLT V-SOL via SNMP direto (Read/Write SNMP) | Observability Twin > Credenciais > OLT (SNMP) |
| Configurar SmartOLT API cloud (não SNMP) | Configurações > SmartOLT Integration card |
| Criar OS / nota técnica | Lousa (Chamados) > "Nova nota" |
| Ver ranking dos técnicos | Avaliação IA |
| Acompanhar tempo de OS | Saúde das OS |
| Fila de aprovações SmartOLT push | Fila SmartOLT |
| Mapa óptico (rede de fibras) | Rede IA |
| Espelho real do estado da OLT | SmartOLT Digital Twin |
| Cobrança / Régua de inadimplência | IA Tesoureira |

## Regras de resposta para o NEO

1. Seja **direto**: aponte o caminho em **2-3 linhas**.
2. Use o formato `Sidebar > Pai > Filho > Aba/Botão`.
3. Se a pergunta cobre uma área que **NÃO está nesta KB**, responda **"Não tenho mapeamento exato para isso, mas tente: ..."** com uma sugestão prudente.
4. Se a pergunta for ambígua, peça esclarecimento (ex: "Você quer OLT V-SOL via SNMP ou SmartOLT API?").
5. Termine com 1 linha de **dica útil** quando aplicável (botão, atalho, data-testid).
